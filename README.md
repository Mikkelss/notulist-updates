# Notulist: nieuwe versies

Hier staan alleen de installers van Notulist, geen code. Een geïnstalleerde
Notulist kijkt zelf om de paar uur in deze releases of er een nieuwere versie
is, en werkt zichzelf bij met een klik.

Eerste installatie: download `Notulist-Setup-<versie>.exe` bij de nieuwste
release en start het bestand.
